## Project Description
This repository contains a **Minishell** implementation in C - a simplified version of a Unix shell. It is NOT the "cub3d" project.

### What is Minishell?
Minishell is a 42 school project that involves creating a simple shell program that can:
- Execute commands
- Handle environment variables
- Manage pipes and redirections
- Implement built-in commands (echo, cd, pwd, export, unset, env, exit)
- Process command line arguments with expansion and globbing

### What is Cub3d?
Cub3d is a completely different 42 school project that involves creating a 3D raycasting engine inspired by Wolfenstein 3D. This repository is NOT related to cub3d.

## Key Features of This Minishell
- Command parsing and tokenization
- Environment variable expansion
- Wildcard globbing
- Built-in commands implementation
- Signal handling
- Memory management with garbage collection
- Readline integration for command line editing
